# 央企创新联合体如何"扩围"又"提质"

**作者**：马大明（大连高级经理学院副研究员）、刘卓（大连理工大学经济管理学院成果转化办公室副主任）
**来源**：《国资报告》杂志2026年第4期

## 核心观点

创新联合体对强化高质量科技供给、促进科技成果转移转化具有重要作用。央企作为"出题人""答题人""阅卷人"三位一体，具备主导创新联合体的天然优势。

**"十四五"成绩**：央企牵头建成23个创新联合体，2025年新吸纳超过100家创新主体参与攻关，1000多个合作项目高质量推进。

**面向"十五五"**：着力补足"主体协同不广、需求转化不深、资源利用不够、利益分配不清、激励保障不足"五大短板。

## 五大破解路径

### 1. 深推动多方积极参与——破解"主体协同不广"

**问题**：部分创新联合体停留在校企合作传统模式，用户单位参与度低、中小企业话语权弱。

**对策**：
- 让"出题人"从单一主体扩展为全链条力量
- 央企主动开放真实应用场景和一线工程需求
- 定向采购、技术共研、产能共享纳入创新网络
- 建立可量化、可追溯的参与度和贡献度评价体系

### 2. 强化科学问题牵引——破解"需求转化不深"

**问题**：大量具有创新潜力的实践积累被当作常规问题消化，无法形成对基础研究的有效牵引。

**对策**：
- 建立"企业出题、专家凝练、联合攻关"的需求转化机制
- 一线技术骨干与高校科研人员共同组建需求专班
- 鼓励科研人员深入企业一线，在真实场景中发现问题
- 将需求凝练能力纳入企业创新能力评价体系

### 3. 促进全面开放共享——破解"资源利用不够"

**问题**：大量创新资源长期封闭在少数机构内部，中小企业缺乏中试条件，高校院所缺乏数据支撑。

**对策**：
- 央企牵头探索成本分担与收益反哺相结合的运作模式
- 分类制定科研设施、工业化数据、中试验证平台服务目录
- 搭建统一的资源信息服务平台，提供在线预约、费用结算等一站式服务

### 4. 完善利益分配机制——破解"利益分配不清"

**问题**：合作前期权属约定不明、中期贡献评价缺失、后期收益分配无据。

**对策**：
- 建立"规则前置、权责明确"的治理框架
- 基础专利归院所、应用专利归企业的分层确权模式
- 引入第三方评估机构，对参与主体的技术贡献进行客观评价
- 动态调整收益分配比例，避免静态固化带来的分配不公

### 5. 优化考核容错政策——破解"激励保障不足"

**问题**：央企考核更强调年度利润、短期回报，导致企业对基础性、长期性项目不敢投、不愿投。

**对策**：
- 延长考核周期、提高亏损容忍度
- 5至10年重大基础研究项目设置里程碑节点评价指标
- 购买联合体成员技术的费用全额计入研发投入
- 出台首台套、首批次、首版次应用的尽职合规免责细则
