# 建设团结有力的领导班子 打造世界一流的服务企业
### ——在公司党委常委会上的发言材料

**江波**

2025年12月1日

同志们：

大家上午好！这是我参加的第一次公司党委常委会会议，在学习完“第一议题”后，研究审议其他议题之前，我想跟大家分享一些关于班子建设的思考和体会。

习近平总书记指出，“领导班子是一个地方、一个单位的‘火车头’，建设好领导班子是夯实党执政的组织基础的关键，也是抓好改革发展稳定各项工作的关键。”“建设一支德才兼备的高素质执政骨干队伍，是我们事业成功的根本保证。”“新时代新征程，我们党要团结带领人民开创事业发展新局面，就必须培养造就堪当民族复兴重任的高素质干部队伍。”“党委书记要做管党治党的书记，当好第一责任人，对党负责，对本地区本单位的政治生态负责，对干部健康成长负责。”可以看出，领导班子不仅是政治方向的引领者、组织文化的塑造者，更是改革发展的推动者、执政能力的体现者。建好领导班子，对于我们准确贯彻落实党中央各项决策部署，团结带领广大干部群众朝着正确政治方向前进，具有极其重要的作用。

为什么我要在首次公司常委会会议上讲班子建设？主要有几方面的原因。第一，是对习近平总书记关于班子建设的重要论述和关于党委书记主要责任的深入学习。第二，是国务院国资委党委领导在同我任前谈话时，希望我团结好班子成员，把班子建设好，把干部队伍和人才队伍建设好，把制度建设好，把民主集中制贯彻好，把班子作用发挥好，形成合力，推动内部改革创新，使航信实现高质量发展。我刚来航信担任“一把手”，和大家都刚接触、刚认识，开展内部调研也刚一周，对公司的情况了解还不多，这个时候谈班子建设、谈团结，没有任何针对性，是最合适的时机。第三，我按照组织安排从电科集团来到航信集团工作，我相信各方面或多或少有一些这样那样的猜测和议论，这都很正常。所以，我想结合自己学习总书记关于班子建设的重要论述、对党委书记的责任要求、《中国共产党章程》中关于班子建设的要求以及国资委党委领导谈话要求的一些领悟，以及我个人长期作为“一把手”的工作经验和体会，谈一谈班子建设问题，目的是使我们新一届公司党委常委会从一开始就明确规矩和要求，把一些关系和要求讲清楚，以便我们在今后的工作中共同遵守、共同维护，统一思想、增强信心、激发干劲、团结合作，推动航信改革发展更上新台阶。会前没有和大家沟通商量要讲的内容，不当之处希望大家批评指正。

作为管党治党第一责任人，党委书记应当管好班子、带好队伍、抓好落实。怎么能管好班子、带好队伍？我认为，首先要抓住最关键的一点，就是搞好团结。团结是班子建设的根本问题，也是领导班子建设的命根子，没有团结就没有一切。只有团结，班子才能有凝聚力、战斗力，才能出成绩、出干部。处理好班子关系，才能实现真正的团结。正如习近平同志说的：“团结是班子建设的重要问题，讲团结是讲政治、顾大局的表现。”“一个好的领导班子，要善于团结协作。大事讲原则，小事讲风格，遇事多通气，多交心，多谅解，真正做到讲团结、会团结。”“在一个班子里就像是在同一条船上，开展工作就好比划船。大家同舟共济，目标一致，心往一处想，力往一处使，形成了合力，这船就能往预定的目标快速前进。”

那么，如何搞好班子团结？核心的一点就是贯彻执行党的民主集中制原则。《中国共产党章程》第二章第十条指出，党是根据自己的纲领和章程，按照民主集中制组织起来的统一整体。习近平总书记也曾指出，民主集中制是我们党的根本组织原则和领导制度，是马克思主义政党区别于其他政党的重要标志。这项制度把充分发扬党内民主和正确实行集中有机结合起来，既可以最大限度激发全党创造活力，又可以统一全党思想和行动，有效防止和克服议而不决、决而不行的分散主义，是科学合理而又有效率的制度。

贯彻执行好党的民主集中制原则，要求我们营造好四种氛围。

**一是营造好民主、开放的氛围。** 航信集团从事的事业是一个庞大的系统工程，我们现在运营的订座、分销、离港、结算等系统，是一个复杂的应用系统。而且，这些系统面临着自主可控的改造，以及解决关键核心技术“卡脖子”的问题。与此同时，在数字化、智能化时代，面临着服务“数据要素 X”“人工智能+”等国家战略，一定会遇到这样那样的问题，有大有小，有难有易。我们要想从单一的库存机票分销平台转型为世界一流的综合信息服务平台，单靠某一个人的智慧是无法实现的，这就需要汇聚集体的智慧。上周我在调研业务部门的时候，也有干部员工提出了关于畅通信息渠道、常态化增加沟通交流机制的意见建议。这些都要求我们领导集体能够搭建多种有利于交流沟通、畅所欲言的平台，营造开放、民主的话语环境。同时，每个人都要本着对组织、对事业高度负责的态度，充分表达自己的真实意见，既要坚持原则、实事求是、敢于斗争，也要注意方法、善于斗争、尊重同志、与人为善。绝不能发牢骚、讲怪话，当面不说、背后乱说，当面一套、背后一套，甚至拉帮结派、讨好卖乖。这是贯彻落实好民主集中制原则的基础和基石。

**二是营造好包容、和谐的氛围。** 大家发扬民主、公开讨论，肯定会有分歧，这恰恰体现了多方智慧的碰撞。如果没有这些多方智慧的碰撞，就不会有创新。创新对于一个企业来说至关重要，这是企业经营的核心和灵魂，是我们保持核心竞争力，实现低成本、高效率、可持续增长的核心驱动力。很多时候我们都需要互相激发，碰撞思维，为公司的发展提供源源不断的新的动能。这就要求每个班子成员都应该以一种平和、包容的心境，虚心、和谐的态度对待不同的意见，从中吸取有益的意见，从而修正自己已有的观点。习近平同志讲过，领导干部“要有胸怀，能容人容事”，这对于维护团结十分重要。这就是一个人的格局。

**三是营造好规范、严谨的氛围。** 光有民主、没有集中，就会贻误我们党的事业。在发扬民主的基础上正确地实现集中，就必须有一系列的规范和规则，例如，各治理主体议事决策的规则、干部选拔任用的程序等。俗话说，欲知平直，则必准绳；欲知方圆，则必规矩。我们开展工作，必须遵守规范、程序和规则。比如，什么问题在什么时间、在什么范围内、以什么程序进行讨论，这些都必须有规范。任何人不能随意扩大知情范围，也不能泄露讨论的过程和内容。又如，如果讨论时有不同意见，就得有规范的流程和规则来集中，不能久拖不决。对于决策的一些结果，个人有不同意见的，可以保留，也可以向上级党组织申诉，但是不能随意更改集体的决定，必须按照决策结果根据各自的分工，抓好落实。常委会的每个成员都要带头尊重制度、尊重程序，形成规范有序的工作文化，这样才能维护常委会的权威。正如习近平总书记强调的：要发扬党内民主，营造民主讨论的良好氛围，鼓励讲真话、讲实话、讲心里话，允许不同意见碰撞和争论，同时善于进行正确集中，防止议而不决、决而不行。

**四是营造好团队的氛围。** 我们在座的班子成员都是国务院国资委党委任命的干部，每个人身上都肩负着很重的责任。国资委党委期望我们形成一个团结的、有凝聚力和战斗力的班子，但是，由于我们每个同志的成长经历不一样，生活环境不一样，专业背景不一样，有的是从上级单位来的，有的是从其他企业来的，也有从航信一步步成长起来的。再加上，每个人的性格特征、行事风格也各不相同，这个时候往往有思维、认知、判断上的区别。那要如何共事？作为党委书记，我认为大家共同做好这三点即可配合得很好：一是班子成员都要尊重欣赏他人多姿多彩的个性，二是班子成员都要善于倾听和尊重他人不同视角的意见，三是班子成员都要学会在遇到矛盾时最大限度地约束自己的个性，尤其是遇到个人利益问题时，首先要克制自己，按制度办事，寻求大家都能欣赏的共性，找到“最大公约数”，这样才能形成相互理解、相互支持、相互帮助、相互补台的工作默契。我们来自五湖四海，年龄也各不相同，大家都是为了把航信打造成世界一流企业的共同目标走到一起，我认为这是一种缘分。我们在一个团队里共事，既是同志，又是战友。我们要珍惜这份同志之情、战友之谊，首先要讲政治、讲原则、讲是非，同时又要讲感情、讲关心、讲支持，还要多欣赏、多帮助、多补台，在矛盾中多谦让、生活中多关心、困难中多担当，共同营造出表达不同意见建议、充分发挥作用的空间和余地，打造“讲团结不是要搞一团和气，讲和谐不是要‘和稀泥’”的工作氛围。要按照总书记所说的敢于斗争、善于斗争来营造这种工作氛围。比如在讨论问题时，我们可以尽情发表自己的想法和观点，甚至可以关起门来吵一吵，红红脸、出出汗，但是走出门外，都要笑脸相对，一旦决定就要坚决执行。

我们实行的民主集中制，是又有集中又有民主、又有纪律又有自由、又有统一意志又有个人心情舒畅生动活泼的制度，是民主和集中紧密结合的制度。在民主集中制的基本原则中，最核心的体现之一就是，党的各级委员会实行集体领导和个人分工负责相结合的制度。凡属重大问题都要按照集体领导、民主集中、个别酝酿、会议决定的原则，由党的委员会集体讨论，作出决定；委员会成员要根据集体的决定和分工，切实履行自己的职责。

实现充分发扬党内民主和正确实行集中的有机结合，首先要坚持和加强党的全面领导。党政军民学，东西南北中，党是领导一切的。习近平总书记指出，坚持党的领导、加强党的建设，是我国国有企业的光荣传统，是国有企业的“根”和“魂”，是我国国有企业的独特优势。坚持党对国有企业的领导不动摇，发挥企业党组织的领导核心和政治核心作用，保证党和国家方针政策、重大部署在国有企业贯彻执行。具体来讲，就是要严格落实“两个一以贯之”——坚持党对国有企业的领导是重大政治原则，必须一以贯之；建立现代企业制度是国有企业改革的方向，也必须一以贯之。党委的主要职责是把方向、管大局、保落实，把方向就是把握正确的政治方向和发展方向，确保组织在思想和行动上与党的理论和路线方针政策保持一致，用实际行动来拥护“两个确立”、践行“两个维护”；管大局就是抓大事、议大事，站在党和国家的事业大局中找准我们航信的定位和布局，谋划和决策全局性、战略性、前瞻性的重大问题；保落实就是党管干部、党管人才，管好人，管人的选拔、任用和分配激励，确保党中央的决策部署和党委的决议决定能够落到实处、见到实效，把党的领导融入公司治理的决策、执行和监督的各个环节里面去。同时，要建设好股东会、董事会、经理层。董事会的主要职责是定战略、作决策、防风险，就是要确定公司长远的发展方向、目标和实现路径，对关系全局和运行的重要事项、问题及方案进行判断和拍板，识别、评估、预警和管控可能阻碍战略实施、影响决策落地，甚至危及组织生存的各种内外部不确定性。经理层的主要职责是谋经营、抓落实、强管理，就是要谋划经营活动，将既定的战略、决策和经营计划转化为具体的行动和可衡量的结果，通过建立和完善组织架构、制度流程、激励机制等，提升公司内部运转的规范化、精细化和高效化水平，提升效益、增强竞争力，实现可持续发展。同时，按《中华人民共和国公司法》规定，公司是企业法人。法人处于经济建设的领导中心地位，所以有法人责任。党的领导和法人治理融合，是中国特色现代企业制度的显著特征。董事长、党委书记一肩挑，就是要确保公司重大问题科学决策和高效执行有机统一。党委处于领导地位发挥作用，公司其他治理主体应该自觉接受党委领导，不缺位、不越位，不能相互替代，更不能各自为政。

贯彻落实好“两个一以贯之”，要处理好几个关系。

**一是处理好正职之间的关系。** 党委书记、董事长和总经理都是公司的主要领导，党委书记、董事长对公司的改革发展和党的建设负有全面责任，总经理负责公司日常的经营管理。我和荣顺同志，一个是“班长”，一个是“副班长”，我们都应该带好这个团队。我个人认为，管理主要就是沟通，这点特别重要。上上周二，正式宣布任命后，我和荣顺同志单独聊了一个多小时，我们都能开诚布公，一致同意要团结好班子成员，让我们的团队能有更强的凝聚力和战斗力，都能摆正位置，给对方多一份理解，多一份尊重，相信这会给我们后期的高效配合、处理好相互关系起好带头作用，打下很好的基础。

**二是处理好正副职之间的关系。** 首先，我们都在一个班子里工作，是一个团队，我们都要自觉维护好常委会的整体功能和整体形象，维护好常委会的名誉和权威。第一，正职要充分尊重和关心副职，遇事多听副职的意见，放手发挥好副职的作用，创造环境让副职独当一面，遇到问题勇于为副职承担责任。第二，副职要充分尊重和体谅正职，自觉维护正职的中心地位。把正职既当领导又当战友，工作中服从指挥，遇到问题坦诚相见，相互帮助、敢于担当。遇到非原则性的不同意见时，要充分理解和尊重正职的意见，不要固执己见。第三，副职与副职之间，既讲分工，又讲分工不分家，大家要合作共事，团结协作，相互帮助，相互补台。第四，班子成员之间的相互沟通极为重要，要形成良好的沟通机制，遇到事情及时商量、及时沟通、彼此尊重。要切实做好会前的沟通和酝酿，没有形成统一意见时，不轻易上会研究讨论，确保沟通和决策的质量和效率。我曾经多年在不同单位当过“一把手”，有个深刻的工作体会，凡是遇到重大的事情，真正起决定性作用的还是会前沟通和协商，会前充分沟通，协商好的事情上会，会很快形成统一意见和决策。

这些是我关于班子建设，尤其是团结队伍方面的一些思考和体会。这些都是一些原则性的理念和想法，有关职能部门要在后续的制度建设中逐步规范和细化，确保我们在工作中遵循既定的规则与流程，有据可查、有理可依，不断提高我们议事决策、贯彻执行的效率和能力。我想，如果班子成员对这些都能在思想上形成共识，而且做好实践，后续一定能为我们贯彻落实好习近平总书记对国资央企的重要指示批示精神，切实履行我们的使命责任，服务国家战略，落实好国务院国资委党委的要求提供更加强大的动力；公司党委常委会一定会为公司各级班子做好表率作用，一级做给一级看、一级带着一级干，为以钉钉子精神带领全体航信人向着建设世界一流综合信息服务企业的目标迈进，注入更加自信的底气！

以上如有不当之处，欢迎大家批评指正。

谢谢大家！
