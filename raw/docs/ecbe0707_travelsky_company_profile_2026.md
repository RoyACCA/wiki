# 中国民航信息集团有限公司

中国民航信息集团有限公司（简称“中国航信”）是隶属于国务院国资委管理的中央企业，是重要信息基础设施运营服务的国家队、航旅数字生态网络的主力军和国家战略的重要科技力量。中国航信拥有航空旅游信息服务领域领先的科技创新体系，所运营的信息系统被列为国务院监管的八大重点系统之一。公司肩负着服务国家交通强国战略、推动航旅产业数字化转型、服务国计民生的重要使命，构建了支撑民航数字化发展的订座、离港、分销、结算4大信息系统，是唯一全集团以信息服务为主业的中央企业。

中国航信起步于1979年，前身是中国民航计算机信息中心。2000年10月，中国民航计算机信息中心联合国内20家航空公司发起成立中国民航信息网络股份有限公司，并于2001年2月在香港联交所主板挂牌上市交易（股票代码：00696.HK）。2002年10月，经国务院批准，正式组建中国民航信息集团公司。2008年7月，中国民航信息集团公司以中国民航信息网络股份有限公司为主体，完成主营业务和资产重组并在香港成功整体上市。2018年1月，完成公司制改制，更名为中国民航信息集团有限公司。

经过40余年持续发展，中国航信已拥有遍布全国及海内外近70家分子公司及非控股公司，超过10000余人的高素质员工队伍。服务范围延伸至300多个国内城市、100多个国际城市。为40余家国内航空公司、10余家地区及海外航空公司、260余家国内机场、190余家海外机场提供信息系统服务，跻身世界第三大全球航空旅游分销系统（GDS）、全球最大中性客票（BSP）数据处理中心。连续多年获评国家高新技术企业、国家知识产权优势企业、中国软件服务业企业信用评价3A级企业，列入国家鼓励的重点软件企业清单。拥有有效专利900余件，参与制定国家标准、行业标准等70余项。多次荣获国家科技进步奖、国家科技攻关重大科技成果奖、民航科技进步奖、交通运输协会科学技术奖等逾百项。获评民航行业首个国家企业技术中心、国家绿色数据中心等荣誉，获得国际软件能力成熟度模型CMMI最高等级五级、测试成熟度模型集成TMMI最高等级五级、国家数据管理能力成熟度（DCMM）四级、国家数据安全能力成熟度（DSMM）四级等认证。所属航旅纵横获评中国创新力企业百强等荣誉。

立足新时代，中国航信坚持以习近平新时代中国特色社会主义思想为指导，在国家所需中明确使命责任，在行业所趋中锚定发展方向，在航信所能中明确发展路径，牢记央企姓党根本属性，以建设世界一流航旅综合智能信息服务企业为愿景，围绕“十五五”时期公司战略定位与发展目标，构筑“安全筑基、主业焕新、新业升级”的发展布局，全面激活增长动能。坚持根脉深植、红色基因铸魂，以实干服务国家战略，以行动践行国企担当；坚持创新驱动、蓝色基因立身，推动产业创新与科技创新深度融合，筑牢核心竞争力；坚持根植产业、绿色基因固本，在创新服务模式、优化服务体验中巩固竞争根基，推动中国民航数字化建设迈向更高水平。
