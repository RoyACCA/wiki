## 二、逐项差距详解

### 2.1 统计口径体系缺失（最紧迫）

**南航已建立：**
- 战新营收、战新利润
- 人工智能投入
- 人工智能营收、人工智能利润

**中国航信现状：**
> 雷哥反馈：这些统计口径还都没有。

**影响：**
- 国资委"AI+"行动、战新产业统计均依赖准确数据
- 口径缺失 → 无法量化成绩 → 无法争取资源 → 恶性循环
- 年报、专项汇报数据可信度存疑

**建议行动：**
1. 尽快与财务、战略部门对齐战新产业目录口径
2. 参照国资委战新产业分类标准，建立AI专项统计维度
3. 明确"人工智能营收"认定标准（产品收入？平台服务收入？内部赋能折算？）

---

### 2.2 AI运营主体缺失

**南航：** 成立**南航数字科技有限公司**，专注数字化运营

**中国航信现状：**
> 计划成立AI工程中心，但迟迟没有进展。

**差距本质：**
- 无专业化运营主体 → AI能力分散在各业务系统，无法集约
- 外部合作、商务拓展、资质申请均缺乏统一出口
- 与南航数字科技的差距会越拉越大

**建议行动：**
1. 全力推进AI工程中心成立，是今年最紧迫的制度性任务
2. 如果实体成立周期长，建议先建立"虚拟AI运营中心"机制，明确责任主体

---

### 2.3 技术经纪人制度缺失

**南航：** 专业化培养107名技术经纪人，建立完善的成果转化制度体系

**中国航信现状：**
- 技术经纪人制度未建立
- 成果转化机制不清晰
- 专利运营停留在"申请-维护"层面，未形成"专利→产品→收入"闭环

**建议行动：**
1. 建立技术经纪人选拔和培养制度
2. 明确成果转化激励（收益分成、里程碑奖励）
3. 参照南航"从纸面到地面"的提法，梳理公司专利资产，识别可转化产品

---

### 2.4 揭榜挂帅机制未落地

**南航：** 通过"揭榜挂帅"机制发布16项攻关榜单，吸引顶尖团队攻坚

**中国航信现状：**
- 国资委有要求
- 内部机制未建立

**建议行动：**
1. 梳理公司AI及科技创新领域的关键技术难题
2. 建立"揭榜挂帅"发布机制和评审机制
3. 明确揭榜成功的激励政策（资金、荣誉、晋升通道）

---

### 2.5 战略定位差距

**南航：** 创新驱动战略置于公司五大战略核心位置，有明确的使命和愿景描述

**中国航信现状：**
- 科技创新更多是归口管理职能，未上升为公司战略层
- 公司层面的科技创新使命、愿景描述不够清晰

**建议行动：**
1. 在公司"十五五"规划中，明确科技创新/AI的战略定位
2. 提炼航信科技创新使命愿景，争取纳入公司战略表述

## 三、南航制度建设的启发

南航已把科技创新从"想法"变成"制度"，形成六大军级闭环：

```
洞察机会 → 孵化项目 → 成果转化 → 人才建设 → 平台支撑 → 生态构建
     ↑                                                        ↓
     ←——————————————————————————————————————————————————————↓
```

这个闭环的关键是**每个环节都有制度保障**：
- 机会洞察：产业布局 + 主攻方向明确
- 孵化项目：研发投入承诺 + 课题管理制度
- 成果转化：107名经纪人 + 收益分配制度
- 人才建设：揭榜挂帅 + 外部专家引入
- 平台支撑：四大高能级平台
- 生态构建：创新挑战赛 + 联合体参与

相比之下，航信目前更多是**点状推进**，缺乏系统性制度闭环。

## 四、优先级建议

| 优先级 | 事项 | 紧迫理由 |
|---|---|---|
| 🔴 P0 | 建立战新及AI统计口径 | 数据是基础，口径不对其他都是空中楼阁 |
| 🔴 P0 | 全力推进AI工程中心成立 | 无运营主体，其他工作无法集约 |
| 🔴 P1 | 建立技术经纪人制度 | 成果转化无队伍，专利无法变现 |
| 🔴 P1 | 推进揭榜挂帅机制落地 | 国资委要求，且是调动团队积极性的有效手段 |
| 🔴 P2 | 争取研发投入强度提升 | 有投入才有产出 |
| 🔴 P2 | 提炼公司科技创新使命愿景 | 战略定位需清晰 |
| ⚠️ P3 | 核实航信自身AI算力、场景等数据 | 对标需要准确数据支撑 |
