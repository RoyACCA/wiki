# 2026年十五五规划纲要发布

**来源**: 网页搜索（2026-05-07）
**搜索关键词**: site:ndrc.gov.cn 战略性新兴产业 未来产业 人工智能 新型工业化
**原始链接**: https://www.ndrc.gov.cn/fggz/fzzlgh/gjfzgh/202603/U020260317369114704096.pdf

## 主要内容

### 十五五规划纲要发布（2026年3月13日）
- 十五五规划纲要正式发布
- "建设现代化产业体系巩固壮大实体经济根基"独立设为第二篇
- 方向升级：十四五"高端化、智能化、绿色化" → 十五五"**智能化、绿色化、融合化**"（新增"融合化"）
- 制造业：保持制造业比重基本稳定 → **保持制造业合理比重**

### 战略性新兴产业（九大领域，新增智能网联新能源汽车、机器人）
1. 新一代信息技术
2. 新能源
3. 新材料
4. 智能网联新能源汽车（新增）
5. 机器人（新增）
6. 生物医药
7. 高端装备
8. 航空航天

### 未来产业（六大规模方向）
1. 量子科技
2. 生物制造
3. 氢能和核聚变能
4. 脑机接口
5. 具身智能
6. 第六代移动通信（6G）

### 发改委解读要点
- **郑备**（副主任）：全方位推进数智技术赋能，实施"人工智能+"行动，促进生产方式深层次变革
- **袁达**（秘书长）：推动出台《碳达峰碳中和综合评价考核办法》，推进能源降碳、产业降碳、生产生活节约增效
- **白京羽**（创新和高技术发展司司长）：梯次布局新兴产业→新兴支柱产业→未来产业

### 工信部2026年十个方面重点（2025年12月）
- 建设一批高质量行业数据集，形成重点行业数字化转型场景图谱
- 深化中小企业数字化赋能专项行动
- 推进"人工智能+制造"专项行动
- 2026年1月：工信部部长部署深化拓展"人工智能+"、推进建设三大国际科创中心
- 2026年4月13日：部署六项重点任务推进工业和信息化质量工作，深化人工智能赋能质量提升
