# Concept: 启航大模型（QiHang LLM）

## Summary

启航大模型由航信资本运营与创新业务部打造，是民航行业大模型，通过国家网信办生成式人工智能服务备案（2025年4月29日，序号394，属地国资委），同时"民航场景自然语言交互算法"和"民航客服自然语言交互算法"两个核心算法通过深度合成服务算法备案。系国资央企第9家备案大模型，第2个完成备案的民航行业大模型。

## Details

### 基本信息

| 项目 | 内容 |
|---|---|
| 模型名称 | 启航大模型 |
| 研发单位 | 资本运营与创新业务部 |
| 备案单位 | 中国民航信息网络股份有限公司 |
| 备案编号 | ZhongyangQiYe-QiHang-202503310007 |
| 备案时间 | 2025年4月29日 |
| 网信办备案批次 | 2025年4月至6月 |
| 备案序号 | 394 |
| 属地 | 国资委 |

### 算法备案

| 算法名称 | 备案编号 | 序号 | 角色 | 主要用途 |
|---|---|---|---|---|
| 民航场景自然语言交互算法 | 网信算备110113140187301250011号 | 121 | 服务技术支持者 | 文本生成，服务企业端客户 |
| 民航客服自然语言交互算法 | 网信算备110113140187301250029号 | 181 | 服务提供者 | 对话生成，应用于人工智能民航客户服务平台（APP） |

### 民航大模型备案地位

- **国资央企第9家**完成备案的大模型
- **第2个**完成备案的民航行业大模型（第1个为千穰大模型）
- 同时完成大模型备案 + 深度合成算法备案（"双备案"）

### 核心优势

1. **深度融合民航业务场景**：具备多任务泛化能力
2. **系统对接能力**：能对接航信业务系统接口，深度整合民航生产业务知识
3. **多场景服务**：支撑从智能客服到运行决策的多场景服务
4. **智能客服优化**：在民航客服领域显著提升复杂问题自动处理能力

### 战略定位

启航大模型以"启航"为名，定位为新质生产力引擎，全面驱动民航全产业链高质量发展。

### 重大荣誉

2025年10月，启航大模型入选**中央企业十大创新成果**（2025中国移动全球合作伙伴大会算力网络LHT分论坛）。

> **部门归属说明**：启航大模型由**资本运营与创新业务部**研发。据2026年组织调整，原资本运营与创新业务部的"启航"大模型相关工作已并入**智能安全业务部**（与航旅链/区块链同归口）。
