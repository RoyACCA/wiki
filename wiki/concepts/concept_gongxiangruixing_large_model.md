# Concept: 共翔睿行大模型（GongXiangRuiXing LLM）

## Summary

共翔睿行大模型由中国航信航空数字化产品事业部研发，于2025年12月31日通过国家生成式人工智能服务备案，同时于2025年11月通过"中国民航共翔睿行文本生成算法"国家深度合成服务算法备案，正式成为"双备案"大模型。依托与中国电信联合建设的中央企业云计算创新联合体，面向民航关键业务环节研发。

## Details

### 基本信息

| 项目 | 内容 |
|---|---|
| 模型名称 | 共翔睿行 |
| 研发单位 | 航空数字化产品事业部 |
| 备案单位 | 中国民航信息网络股份有限公司 |
| 大模型备案号 | Beijing-GongXiangRuiXing-202511150157 |
| 大模型备案时间 | 2025年12月31日 |
| 算法备案编号 | 网信算备110113140187301250037号 |
| 算法备案时间 | 2025年11月 |
| 算法备案序号 | 604（境内深度合成服务算法清单） |
| 北京市新增备案序号 | 4 |
| 技术背景 | 依托中央企业云计算创新联合体（中国电信联合） |

### 发展历程

1. **2025年4月**：第八届数字中国建设峰会上正式发布共翔睿行品牌
2. **2025年10月**：通过商标注册
3. **2025年11月**：通过"中国民航共翔睿行文本生成算法"国家深度合成服务算法备案（序号604）
4. **2025年12月31日**：通过国家生成式人工智能服务备案（北京序号4）
5. **正式完成**：国家算法和大模型"双备案"

### 战略背景

共翔睿行是中国航信全面落实国务院国资委两项政策文件的产物：
- 《中央企业"AI+"产业发展任务书》
- 《国资央企"AI+"专项行动实施要点（2025）》

### 核心定位

面向民航关键业务环节，以提升旅客出行体验和航空公司运行品质为宗旨，深度融合AI前沿技术与民航业务应用，挖掘民航数据要素核心价值，促进民航业从数字赋能的互联网服务向智能驱动的新型服务方式演进。

> **部门归属说明**：共翔睿行由**航空数字化产品事业部**研发。据2026年组织调整，原资本运营与创新业务部的AI相关工作并入**智能安全业务部**（航旅链/区块链/启航大模型归其管辖）；共翔睿行仍归属航空数字化产品事业部。
