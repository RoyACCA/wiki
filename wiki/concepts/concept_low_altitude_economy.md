# Concept: Low Altitude Economy（低空经济）

## Summary

低空经济是以低空空域（通常指**1000米及以下**，部分场景扩展至**3000米**）为核心依托，以无人机、eVTOL、通航飞行器为载体，涵盖基建、制造、服务全链条的综合性经济形态。

**核心数据**：
- 2025年市场规模：**8500~15000亿**（同比+28%）
- 2026年预计：**破万亿**
- 2035年目标：**3.5万亿**

## Details

### 什么是低空经济

低空经济以先进飞行器为载体，依托新型基础设施建设和空域管理，融合多产业的三维经济形态，涵盖四大场景：

| 场景 | 典型应用 | 核心价值 |
|------|----------|----------|
| 生产作业 | 电力/管道/河道巡检、农业植保、测绘 | 效率提升15-20倍，降本 |
| 交通运输 | 城市及偏远地区物流配送、即时配送 | 成本降10-40%，突破地形限制 |
| 公共服务 | 应急救援、城市治理（消防/警务/防灾） | 满足政府刚需，高效专业 |
| 消费活动 | 文旅观光、商业航拍、飞行体验 | 消费意愿强，模式灵活 |

### 三大核心赛道

**无人机（当前主力）**
- 2025年全球市场2202亿元，中国1452亿元
- 工业级占比68%，技术向AI赋能、长续航升级
- 应用朝行业一体化、消费工具化发展

**eVTOL（未来重点）**
- 2025年全球市场158.2亿美元，中国57.5亿元
- 截至2025年11月，中国eVTOL年度订单超300亿元
- 聚焦载人和载物场景，适航认证加速推进商业化
- 代表进展：国产800公斤级重载eVTOL AR-E800首飞成功

**通用航空（传统成熟）**
- 截至2025年7月，有人机运营企业801家
- 无人机运营企业突破1.99万家
- 2025年上半年无人机飞行时间2447万小时

### 发展阶段

```
1.0 试点示范（2025年前）  →  以无人机为主，市场培育
2.0 规模应用（2027年）    →  eVTOL量产+商业化落地
3.0 生态成熟（2035年）    →  3.5万亿目标达成
```

### 政策脉络

| 时间 | 节点 |
|------|------|
| 2010 | 首次提出"低空经济"概念 |
| 2021 | 首次纳入国家规划 |
| 2023 | 明确为战略性新兴产业 |
| 2024/2025 | 连续两年写入政府工作报告 |
| 2025 | 十五五规划列为新兴支柱产业 |

顶层法规：《国家空域基础分类方法》界定空域权限，低空改革持续深化。

### 地方进展

- **上海**：大飞机产业基础支撑eVTOL集群化发展，2026年预计实现5G-A低空智联网络全域覆盖
- **深圳**：全产业链优势，2026年底目标建成低空起降点1200个+，商业航线超1000条
- **重庆**：立足山区地形，重点拓展低空旅游、山区物流

### 核心挑战

- 顶层法规滞后于产业发展
- 商业模式尚不成熟
- 技术研发成本高
- 基础设施（设施网、空联网、起降点）总量不足且布局失衡

→ 突破路径：制度完善 + 场景拓展 + 产业链协同
