# 中国航信外出审批管理规定

## Summary

航信集团办发〔2026〕2号《中国航信外出审批管理规定》，2026年4月15日发布，适用于公司党委书记、总经理、党委副书记、纪委书记、总会计师、副总经理、部门正副职级领导干部及所属各分子公司负责人等，明确离开驻地办公区域半天以上的外出审批程序，逐级报批至党委书记（董事长）或总经理批准。文件同时废止原中航信办发〔2017〕38号、航信股份发〔2023〕27号两项旧规。

## Details

### 文件信息

- **文号**：航信集团办发〔2026〕2号
- **发布机关**：中国民航信息集团有限公司办公室
- **发布日期**：2026年4月15日
- **发起日期**：2026年4月15日
- **替代文件**：中航信办发〔2017〕38号、航信股份发〔2023〕27号

### 适用人员

1. 公司党委书记（董事长）、总经理
2. 公司党委副书记、纪委书记、总会计师、副总经理
3. 公司总经理助理级领导干部
4. 公司部门正职级、副职级领导干部
5. 所属一类、二类、三类及其他类公司负责人
6. 公司各单位（部门）内设机构负责人及员工

### 外出定义

本规定所称**外出**是指离开驻地办公区域半天（含）以上。

### 审批程序

| 人员 | 审批程序 |
|------|----------|
| 党委书记（董事长） | 按国务院国资委有关规定履行中央企业负责人外出报告申请程序 |
| 总经理 | 经党委书记（董事长）同意，并履行中央企业负责人外出报告申请程序 |
| 党委副书记、党委常委、副总经理、纪委书记 | 报党委书记（董事长）批准 |
| 总经理助理级领导干部 | 报总经理、党委书记（董事长）批准 |
| 职能部门正职级领导干部 | 报分管领导、总经理、党委书记（董事长）批准 |
| 职能部门副职级领导干部 | 经本单位正职同意，报分管领导批准 |
| 一类、二类公司正职 | 报总经理、党委书记（董事长）批准 |
| 一类、二类公司副职 | 经党组织书记同意，报总经理批准 |
| 三类公司负责人 | 报总经理批准 |
| 其他类公司负责人 | 报所属业务部门板块总经理同意 |
| 内设机构负责人 | 报本单位（部门）正职同意 |
| 员工 | 报内设机构负责人同意 |

### 附则

- **因私请休假**：在新一代人力资源管理系统提交休假申请，按上述审批权限审批
- **公共假期外出**：领导干部离开工作所在地区时，需在OA系统提交外出申请
- **身兼多职**：按最高职务或外出事宜所涉及职务报批
- **因公外出凭证**：凭申请单办理购票、借款及报销手续
- **特殊情况**：不能及时完成审批者，应电话或短信请示报批同意，后补办手续
- **解释权**：由公司办公室负责解释
- **施行日期**：自发布之日起施行
