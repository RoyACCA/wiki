# Concept: 千穰大模型（Qianrang）

## Summary

千穰（Qianrang）是中航信移动科技有限公司研发的民航行业大模型，参数规模超1000亿，2023年8月发布，2024年7月通过**国家网信办生成式人工智能服务备案**（备案号ZhongYangQiYe-QianRang-202406200001，第四个通过备案的央国企大模型），**非双备案**。民航领域首个生成式大模型，已落地智能客服、视觉监控、航班预测等场景，累计服务**40+**民航机构（2025年8月更新）。

## Details

### 基本信息

| 项目 | 内容 |
|---|---|
| 模型名称 | 千穰大模型（Qianrang） |
| 研发单位 | 中航信移动科技有限公司（移动科技） |
| 发布时间 | 2023年8月 |
| 备案单位 | 中航信移动科技有限公司 |

| 备案时间 | 2024年7月12日 |
| 网信办备案序号 | 168（2024年8月批次） |
| 属地 | 国资委 |
| 备案类型 | **生成式人工智能服务备案（单备案）**，非双备案 |
| 模型类型 | 民航垂直领域大模型 |
| 参数规模 | 1000亿+ |
| 模型ID（AI环信） | 1499（2025-08-04更新） |
| 技术架构 | 融合视觉大模型、语言大模型、多模态大模型、计算大模型 |

> **备案类型说明：** 我国大模型备案分两种——（1）生成式人工智能服务备案（针对面向公众提供服务的生成式AI产品）；（2）深度合成算法备案（针对语音合成、图像生成等特定算法）。"双备案"指同时取得两者。千穰目前仅有生成式人工智能服务备案，尚未取得深度合成算法备案。[[concept_qihang_large_model]]是双备案。

### 技术架构

千穰采用"通用大模型+垂域增强"的技术路线：

1. **数据基座：** 500G预训练文本（民航占比10%）；500万民航图片；日均10万+架次航班数据；50万指令数据（民航30万）
2. **垂域增强三阶段训练：**
   - 增量预训练：数十万民航多任务多轮指令数据
   - 多任务微调：Text2SQL、多轮对话、工具调用、阅读理解等
   - 推理与系统集成训练：任务拆分+思维链+接口调用指令数据
3. **知识增强：** 百万级民航知识库 + 混合检索（RAG：向量+关键词）+ 知识图谱
4. **多模态：** 跨模态知识图谱（文本/图像/航班时序数据）；知识驱动的多模态训练
5. **工具调用：** Text2SQL + 多接口编排，实现复杂民航系统联动

| 航班ETA预测误差 | <1.5分钟 | — |
| 机坪违规检出率 | 95% | — |
| 保障节点识别精度 | 95%+ | — |
| 民航客评分析准确率 | 95% | 效率提升10倍 |

### 算力平台

基于国产化算力研发，在320张910BGPU集群上实现45%+算力利用率，与nvidia高端芯片持平，有效解决海外芯片"卡脖子"问题。

### 应用成果

| 应用产品 | 核心指标 | 投产单位 |
|---|---|---|
| 民航出行助手 | 问答准确率90%+，覆盖航班动态、历史行程分析、民航百科 | 航旅纵横等 |
| 智能客服 | 转人工率降至20%，人工成本降低50% | 乌鲁木齐机场、兰州机场、长龙航空、民航局 |
| 机坪违规预警 | 检出率95%，误报率<10% | 华东空管局、成都双流、烟台、丽江机场 |
| 航班保障节点识别 | 精度95%+ | 华东空管局、成都双流、烟台、丽江机场 |
| 民航客评分析 | 准确率95%，效率提升10倍 | 民航局运输司、成都双流、重庆江北 |
| 民航时序预测 | ETA误差<1.5分钟，首次实现民航时序通用性预测 | 民航局运输司、民航局时刻办 |

> 累计服务**40+**民航机构（2025年8月更新），直接收益2000万+，每年为行业节约上亿成本。

### 战略意义

千穰是民航业首个垂直领域大模型，标志着移动科技在人工智能领域的前瞻性布局和雄厚技术实力获国家认可。千穰的研发成功：
- 实现了大模型对民航复杂专业知识理解和专业实时服务的融合
- 具备可控性好、实时性高、专业性强的优势
- 为[[event_2025travelsky-zhineng-civil-aviation]]智慧民航典型案例奠定了模型基座

> **部门归属说明**：千穰由**中航信移动科技有限公司**（简称移动科技，航信全资子公司）研发，并非航信股份公司内部部门。据2026年组织调整，航信总部的AI相关工作归口**智能安全业务部**。
