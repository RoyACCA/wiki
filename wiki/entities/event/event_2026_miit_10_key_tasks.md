## Summary

2025年12月25-26日，全国工业和信息化工作会议在京召开。会议强调2026年要围绕实现"十五五"良好开局，聚焦重点、抓住关键，突出抓好十个方面重点工作。

## Details

### 十大重点任务速览

| # | 任务方向 | 关键词 |
|---|---------|--------|
| 一 | 巩固工业经济稳中向好 | 十大重点行业稳增长、绿色产品、消费品名品方阵 |
| 二 | 提升产业链韧性和安全 | 重点产业链高质量发展、产业基础再造 |
| 三 | 提升产业科技创新能力 | 中试平台、科技成果转化、国家高新区 |
| 四 | 优化提升传统产业 | 设备更新、数智赋能、卓越质量工程 |
| **五** | **培育壮大新兴产业和未来产业** | **低空经济、6G、具身智能、元宇宙、AI攻关** |
| **六** | **推动信息化和工业化深度融合** | **"人工智能+制造"专项行动、重点行业智能体** |
| 七 | 推动工业绿色低碳发展 | 碳足迹、绿色工厂、节能降碳 |
| **八** | **推动信息通信业高质量发展** | **万兆光网、"毫秒用算"专项行动、数据跨境、低空频率** |
| 九 | 加强优质企业培育 | 小巨人、单项冠军、中小企业服务 |
| 十 | 提高行业治理效能 | 十五五规划、内卷式竞争、标准体系 |

### 与航信相关重点

**任务五（新兴产业和未来产业）：**
- 低空经济：低空经济写入新兴产业支柱名单
- 6G：加强6G技术研发
- 具身智能、元宇宙：完善创新发展政策，开展揭榜挂帅

**任务六（两化深度融合）：**
- 推进"人工智能+制造"专项行动
- 培育重点行业智能体、智能原生企业
- 实施工业互联网和人工智能融合赋能行动
- 壮大工业互联网平台体系

**任务八（信息通信业）：**
- 启动"宽带升级"专项，万兆光网试点
- 深入实施城域"毫秒用算"专项行动（算力网络）
- **出台低空经济发展等领域频率开发利用指南**（直接关联航信低空业务）
- 推动汽车等重点领域数据跨境流动机制
