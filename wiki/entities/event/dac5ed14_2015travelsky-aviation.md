# 2015TravelskyAviation

## Summary
这份文档是**中国民航信息网络股份有限公司（中国航信，TraveSky）**发布的**2015年年度报告**。报告详细披露了公司在2015年1月1日至12月31日期间的财务业绩、业务回顾、公司治理及未来发展战略。以下是对该年报核心内容的深度提炼：。

## Details
这份文档是**中国民航信息网络股份有限公司（中国航信，TraveSky）**发布的**2015年年度报告**。报告详细披露了公司在2015年1月1日至12月31日期间的财务业绩、业务回顾、公司治理及未来发展战略。

以下是对该年报核心内容的深度提炼：

### 核心财务业绩：利润增速跑赢收入
2015年，公司实现了**“收入微增、利润大增”**的结构性优化，主要得益于低毛利的系统集成业务收缩和成本控制。

| 核心指标     | 2015年数值 (人民币) | 同比变动 | 备注                                 |
| :----------- | :------------------ | :------- | :----------------------------------- |
| **营业收入** | **54.72 亿元**      | 📈 +2.5%  | 较2014年微增，主要受集成业务减少影响 |
| **净利润**   | **19.14 亿元**      | 📈 +15.8% | 本公司权益持有人应占盈利             |
| **税前利润** | **23.17 亿元**      | 📈 +21.6% | 盈利能力强劲                         |
| **每股收益** | **0.65 元**         | -        | 基本及摊薄每股盈利                   |
| **派息建议** | **0.166 元/股**     | -        | 建议派发末期股息 (需股东大会批准)    |

*   **成本控制：** 营业成本为37.24亿元，同比下降8.7%。其中，软硬件销售成本大幅下降49.4%，反映了公司业务重心从低毛利的系统集成向高毛利的技术服务转移。
*   **现金流：** 经营活动产生的现金流量净额为**23.83亿元**，同比增长26.9%，主营业务造血能力极强。

### 业务回顾：核心主业爆发，传统业务调整
公司的业务结构在2015年发生了显著变化，航空信息技术服务成为绝对核心。

**1. 航空信息技术服务 (核心引擎)**
*   **收入：** **31.35亿元**（占总收入的57.3%），同比增长9.8%。
*   **规模：** ETD系统处理订座量约**4.71亿人次**（+10.9%）；离港系统在海外/地区机场处理旅客量约2930万人次。
*   **创新产品：** “航旅纵横”APP用户量大增，推出Apple Watch版本及“延误猜一猜”等功能；自助值机产品在115个机场使用。

**2. 结算及清算服务 (高增长)**
*   **收入：** 4.93亿元，同比增长13.9%。
*   **规模：** 处理BSP客票约2.79亿张，代理结算收入达82亿美元；建立了统一清算平台，实现国内全网周清算。

**3. 系统集成服务 (战略收缩)**
*   **收入：** 6.43亿元，同比下降38.1%。
*   **原因：** 公司主动减少低毛利的硬件集成和软硬件销售项目，导致该板块收入大幅下滑，但有效提升了整体利润率。

### 战略布局与基础设施
*   **北京新运行中心：** 位于顺义的重大基建项目。截至2015年底累计支出约17.3亿元，预计2016年将继续投入10.6亿元，建成后将成为公司未来的核心硬件基础。
*   **“十三五”规划：** 2016年是新规划的开局之年，战略重点转向“调结构、防风险”，加大在云计算、大数据、移动互联网等领域的创新投入。

### 公司治理与股权结构
*   **股权结构：** 总股本约29.26亿股。
    *   **内资股 (68.13%)：** 主要由中国民航信息集团公司（约29.29%）及多家国有航空公司（南航、东航、国航集团合计约38.84%）持有。
    *   **H股 (31.87%)：** 在香港联交所上市（00696）。
*   **高层变动：** 崔志雄先生于2016年3月正式当选董事长；年内有多位董事因工作调动或任期届满离任。
*   **税务优惠：** 公司维持“高新技术企业”资格，2015年按**15%**的优惠税率缴纳企业所得税。

### 关键风险与关联交易
*   **关联交易：** 报告详细披露了与主要股东（如南航、东航、国航）的持续交易。由于这些航司既是股东又是大客户，交易价格通常受民航局指导价限制或按公平原则协商。
*   **客户集中度：** 前五大客户贡献了约45%的收入，显示出对大型航空公司客户的依赖。
