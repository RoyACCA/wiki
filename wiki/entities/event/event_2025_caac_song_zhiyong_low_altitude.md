# 宋志勇：高质量发展通用航空和低空经济

## 摘要

2025年1月3日，中国民用航空局党组书记、局长宋志勇在《学习时报》发表署名文章，系统阐述发展通用航空和低空经济的重大意义、现实基础及高质量发展举措。文章指出，低空经济作为新质生产力的典型代表，正快速崛起成为万亿级产业新赛道，2024年规模已超5000亿元，预计2030年有望达到2万亿元。

## 一、发展通用航空和低空经济的重大意义

### 1.1 落实国家战略，为经济社会发展提供新动能

- **产业链特征**：产业链条长、应用场景广、带动能力强、科技含量高
- **核心定位**：培育竞争新优势、打造增长新引擎、开辟产业新赛道
- **战略作用**：加快构建现代化产业体系和强国建设的关键力量
- **融合创新**：融合无人机新型低空生产服务方式，信息化、数字化管理技术赋能
- **三大功能**：改造升级传统产业、培育壮大新兴产业、加快布局未来产业

### 1.2 增进民生福祉，为满足人民生产生活需求提供新供给

- **公共服务领域**：基础设施巡查、应急救援、城市巡逻、森林防火、医疗救护
- **消费应用场景**：影视航拍、空中游览、消费娱乐、文旅、体育产业
- **未来拓展**：无人机物流配送、低空运输、城市空中交通出行
- **社会效益**：降低大众航空消费门槛，促进居民消费升级，支撑共同富裕和区域协调发展

### 1.3 丰富民航业态，为谱写交通强国建设民航新篇章提供新途径

- **产业融合平台**：民航业与相关产业交融互动的重要载体
- **双重价值**：
  - 促进传统通用航空产业迭代升级，补齐发展短板
  - 无人驾驶航空拓展高效出行、物流运输等消费场景
- **数字化转型**：航空与数字技术融合，推动民航产业组织方式、运行管理模式、安全监管体系向智能管理"跃升"

### 1.4 赋能航空制造，为关键技术创新应用提供新空间

- **技术融合**：与新材料、新能源、导航、卫星互联网、5G、大数据、云计算等深度融合
- **产业升级**：推动传统通用航空在材料、设计、制造等领域转型升级
- **战略机遇**：推动我国在全球航空竞争中实现"换道超车"
- **自主可控**：为人工智能、新能源、量子信息、通信技术、先进制造等领域提供市场空间

## 二、发展通用航空和低空经济的现实基础和形势要求

### 2.1 政策支持体系（党中央重大决策部署）

| 时间 | 政策文件 | 核心内容 |
|------|----------|----------|
| 2022年12月 | 《扩大内需战略规划纲要（2022—2035年）》 | 积极发展服务消费，加快培育低空等旅游业态 |
| 2023年12月 | 中央经济工作会议 | 打造低空经济等若干战略性新兴产业 |
| 2024年1月1日 | 《无人驾驶航空器飞行管理暂行条例》 | 促进无人驾驶航空器产业健康有序发展 |
| 2024年3月 | 《政府工作报告》 | 积极打造低空经济等新增长引擎 |

### 2.2 发展现状与数据

| 指标 | 数据 |
|------|------|
| 通航企业数量 | 744家 |
| 通用航空器在册数量 | 3226架 |
| 通用机场数量 | 470个 |
| 无人机运营企业 | 近1.9万家 |
| 国内注册无人机 | 215.8万架 |
| 传统通航飞行（2024年1-11月） | 123万小时（近3年年均增速约12%） |
| 无人机飞行（2024年1-11月） | 2544.9万小时（同比增长15.3%） |

### 2.3 试验区与试点建设

- **民用无人驾驶航空试验区**：17个（覆盖城市、海岛、支线物流和综合应用拓展等典型场景）
- **试验基地**：3个
- **无人机低空物流体系建设试点**：已批准

### 2.4 应用场景拓展

- **传统通航作业**：飞行培训、短途运输、农林植保、基础设施巡查
- **新兴业态**：空中游览、跳伞飞行、应急救援、医疗救护
- **无人机应用**：消费娱乐、地理测绘、影视航拍、物流配送
- **特殊场景**：森林消防、通信中继、人工影响天气、边防后勤保障
- **未来探索**：城市空中交通出行

### 2.5 存在问题与挑战

- 顶层设计不足
- 要素投入不够
- 创新能力不强
- 治理水平不高
- 市场活力有待激发
- 管理理念、法规体系、服务保障体系、监管技术手段与安全发展要求不适应

### 2.6 发展趋势研判

- **市场规模**：目前超5000亿元，2030年有望达到2万亿元
- **发展方向**：应用场景多元拓展、基础设施加快建设、标准体系健全完善、行业治理逻辑重塑
- **核心原则**：统筹处理好发展和安全的关系，把握好政策的时度效，实现市场需求和安全保障能力动态平衡

## 三、推动通用航空和低空经济高质量发展的举措

### 3.1 牢固树立安全发展理念

- 贯彻总体国家安全观
- 强化低空安全运行监管
- 健全完善差异化精准监管政策机制
- 建立健全各类飞行活动的安全运行规则、标准及监管政策
- 建立健全应急保障机制
- 加强与国际民航组织及国外民航当局合作交流

### 3.2 强化规划政策引领

- 强化规划引领和基础理论研究
- 完善低空运行统计监测制度
- 健全低空经济法规标准框架
- 印发实施《推进通用航空和低空经济安全有序发展实施方案》
- 优化促进高质量发展的政策措施

### 3.3 强化适航审定能力建设

- 完善基于"运行风险、分类管理"的无人机适航审定模式
- 探索引入社会力量支撑适航审定工作机制
- 发挥专家作用，优化适航标准体系，创新审定形式
- 加强人才培养和科技投入
- 加快形成适应需求的适航审定能力

### 3.4 健全飞行服务保障体系

- 统一标准、统一接口
- 推动布局空天地一体的通信导航监视基础设施
- 与城市全域数字化转型协同推进
- 军地民设施数据共用共享
- 完善低空飞行服务法规标准体系
- 构建服务有效、监管有力、数据精准、即时互联的低空飞行服务保障体系

### 3.5 完善低空基础设施体系

- 坚持安全发展、集约高效、智慧绿色导向
- 加大建设和运行管理标准供给
- 强化央地协同、简化审批流程
- 支持垂直起降基础设施加快建设
- 分类简化机场建设程序与标准
- 优化通用机场和起降点布局
- 全面提升基础设施供给质量

### 3.6 加强运营服务市场准入管理

- 统筹兼顾、分类施策
- 聚焦不同场景业态的市场准入、事中事后监管和消费者权益保护
- 以运营人、运营企业的资格能力建设为重点
- 以保障安全运行和提升服务质量为导向
- 完善市场监管政策
- 引导培育低空经济应用场景
- 激发市场活力，规范市场秩序
- 构建良好的市场生态

### 3.7 提升低空运行监管效能

- 统筹发展和安全
- 适应低空飞行活动带来的安全态势变化
- 完善低空运行规则标准
- 明确各级管理主体监管职责
- 创新安全监管理念
- 加快构建"行业管理+社会管理"的分级分类多元治理模式
- 夯实监管能力，提升监管效能
- 以高水平安全保障高质量发展
