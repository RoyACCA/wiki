# Event: 移动科技机场行李智能搬运系统入选北京市首台（套）重大技术装备目录

## Summary

2025年6月，移动科技自主研发的"机场行李智能搬运系统"入选北京市2025年第一批首台（套）重大技术装备目录，领域为"机器人及智能制造装备-机器人-工业机器人"，技术水平达国内领先，获权威认可。

## Details

- **入选时间**：2025年6月（公告时间2025年6月9日）
- **入选目录**：北京市2025年第一批首台（套）重大技术装备目录
- **入选领域**：机器人及智能制造装备-机器人-工业机器人
- **研发单位**：中航信移动科技有限公司（移动科技）
- **技术水平**：国内领先
- **来源**：《移动科技"机场行李智能搬运系统"入选北京市首台（套）重大技术装备目录》，作者：张淑君，浏览量：681

> **部门归属**：移动科技为航信全资子公司，架构独立。
