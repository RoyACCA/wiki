# 2018TravelskyAviationPolicy

## Summary
这份文档是**中国民航信息网络股份有限公司（中国航信，Travelsky）发布的2018年年度报告**。报告详细披露了公司在2018年1月1日至12月31日期间的财务业绩、业务回顾、战略转型及重大资本运作。以下是对该年报核心信息的全面提炼：。

## Details
这份文档是**中国民航信息网络股份有限公司（中国航信，Travelsky）发布的2018年年度报告**。报告详细披露了公司在2018年1月1日至12月31日期间的财务业绩、业务回顾、战略转型及重大资本运作。

以下是对该年报核心信息的全面提炼：

### 1. 核心财务业绩：盈利质量提升

2018年是公司“十三五”规划的关键之年，业绩表现出**利润增速跑赢收入增速**的特征，主要得益于成本控制和业务结构调整。

| 核心指标     | 2018年数值 (人民币) | 同比变动 | 备注                     |
| ------------ | ------------------- | -------- | ------------------------ |
| **营业收入** | **74.72 亿元**      | 📈 +11.0% | 总收入增加约7.38亿元     |
| **净利润**   | **23.25 亿元**      | 📈 +3.4%  | 本公司权益持有人应占盈利 |
| **税前利润** | **26.50 亿元**      | 📈 +0.7%  | 盈利能力保持稳定         |
| **每股收益** | **0.79 元**         | 📈 +2.6%  | 基本及摊薄每股盈利       |
| **派息建议** | **0.269 元/股**     | -        | 建议派发末期股息         |

- **现金流：** 经营活动产生的现金流量净额为**21.41亿元**（2017年为30.63亿元，主要因2017年有大额退税导致基数较高）。
- **税务影响：** 公司维持“高新技术企业”资格，按15%优惠税率缴纳企业所得税。虽然2018年收到了2017年度的退税，但因2018年当期按15%计提，未能像往年一样获得10%的“重点软件企业”税率认定，导致所得税费用较往年增加，一定程度上影响了净利润增速。

### 2. 业务回顾：航空主业爆发，创新业务落地

公司处于中国航空旅游分销价值链的核心环节，业务结构持续优化。

- **✈️ 航空信息技术服务 (核心主业)**
  - **收入：** **41.60亿元**（占总收入的 **55.7%**）。
  - **规模：** ETD系统处理的订座量约**6.44亿人次**（+9.8%）。
  - **亮点：**
    - **“航旅纵横”：** 用户数稳步增长，推出“机场专区”及多款创新产品。
    - **无纸化出行：** “航信通”覆盖国内229家机场，千万级机场全部实现全流程电子化。
    - **国际化：** 系统成功引入俄罗斯皇家航空等4家海外航司，自主研发的低成本航空解决方案正式投产首家海外客户（柬埔寨天空吴哥航空）。
- **💰 结算及清算服务 (稳健增长)**
  - **收入：** 5.79亿元（+4.4%）。
  - **规模：** 处理了约 **3.96亿张** BSP客票，代理结算客货邮运收入及费用达约 **106.7亿美元**。
  - **创新：** 启动了符合NDC/ONE ORDER行业标准的收入结算系统研发，并在四川航空投产上线。
- **🏗️ 系统集成与数据网络 (结构调整)**
  - **系统集成：** 收入9.47亿元（+27.2%），主要由于签约项目增加。
  - **数据网络及其他：** 收入17.86亿元（+14.7%），主要得益于分销信息技术服务及旅游分销服务的增长。

### 3. 战略布局与基础设施

- **北京新运行中心：** 位于顺义的重大基建项目。截至2018年底，一期工程累计支出约**27.5亿元**（占预算的75.2%），预计2019年继续投入约6.6亿元。
- **资本开支：** 2018年资本开支约为10.97亿元，主要用于日常运营、计算机系统维护升级及北京新运行中心建设。
- **研发投入：** 研发投入资金**6.59亿元**，研发团队总人数达3,512名。

### 4. 重大投资与变动

- **退出招商局仁和财险：** 公司此前计划出资成立的“招商局仁和财产保险股份有限公司”因先决条件未达成而终止，公司已收回相关筹建费用。
- **持股招商局仁和人寿：** 继续持有17.5%股权，投资成本8.75亿元。虽然该寿险公司2018年亏损4.07亿元（开业初期投入大），但公司认为其长期前景广阔。
- **引入战略投资者：** 2018年底，中移资本控股有限责任公司收购了1.466亿股公司内资股，成为重要股东（持股约5.01%），标志着公司与运营商在大数据等领域的合作深化。

### 5. 关键风险与未来展望

- **税务风险：** 公司已按15%税率计提2018年所得税，正在申请2018年度“国家规划布局内重点软件企业”资格，若获批可享受10%税率，差额将予以退还。
- **战略方向：** 2019年是新中国成立70周年，公司将继续坚持“调结构、防风险”，重点提升运维保障能力（立业之本）、科技研发能力（创业之源）、市场竞争能力（兴利之根）和客户服务能力（精业之魂）。
