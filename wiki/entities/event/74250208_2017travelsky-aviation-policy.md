# 2017TravelskyAviationPolicy

## Summary
这份文档是**中国民航信息网络股份有限公司（中国航信，Travelsky）**发布的**2017年年度报告**。报告详细披露了公司在2017年1月1日至12月31日期间的财务业绩、业务回顾、战略转型及重大资本运作。以下是对该年报核心内容的全面提炼：。

## Details
这份文档是**中国民航信息网络股份有限公司（中国航信，Travelsky）**发布的**2017年年度报告**。报告详细披露了公司在2017年1月1日至12月31日期间的财务业绩、业务回顾、战略转型及重大资本运作。

以下是对该年报核心内容的全面提炼：

### 核心财务业绩：利润受税务优惠调整影响
2017年是公司“十三五”规划的关键之年，虽然营业收入保持增长，但净利润因税务优惠政策调整（未能获得10%优惠税率）而出现小幅下滑。

| 核心指标     | 2017年数值 (人民币) | 同比变动 | 备注                     |
| :----------- | :------------------ | :------- | :----------------------- |
| **营业收入** | **67.34 亿元**      | 📈 +8.2%  | 总收入增加约5.11亿元     |
| **净利润**   | **22.49 亿元**      | 📉 -7.1%  | 本公司权益持有人应占盈利 |
| **税前利润** | **26.32 亿元**      | 📉 -8.3%  | 受所得税费用增加影响     |
| **每股收益** | **0.77 元**         | 📉 -6.0%  | 基本及摊薄每股盈利       |
| **派息建议** | **0.253 元/股**     | -        | 建议派发末期股息         |

*   **现金流：** 经营活动产生的现金流量净额为**30.63亿元**，虽然较2016年有所下降，但仍保持充裕。
*   **税务影响：** 公司维持15%的高新技术企业优惠税率，但未获得“国家规划布局内重点软件企业”的10%税率。虽然公司在2017年收到了2016年的退税，但2017年度按15%计提的所得税费用较往年增加，导致净利润承压。

### 业务回顾与战略转型
公司在2017年确立了**“构建大平台、汇聚大数据、开展大服务”**的战略路径，并完成了新一代民航旅客服务系统的建设。

**1. 航空信息技术服务 (核心支柱)**
*   **收入：** **38.79 亿元**（占总收入的 **57.6%**），同比增长10.9%。
*   **规模：** ETD系统处理订座量约 **5.86亿人次**（+11.8%）；APP系统在100个机场处理出港旅客量约1600万人次。
*   **创新：** “航旅纵横”APP用户数稳步增长，首次提供国际行程在线值机；“航信通”实现无纸化通关，覆盖国内百余家机场；自助值机系统（CUSS）在164个机场使用。
*   **技术突破：** 新一代民航旅客服务系统（New Generation System）全部功能开发完成并通过验收，拥有自主知识产权。

**2. 系统集成与数据网络 (结构调整)**
*   **系统集成：** 收入 **7.44亿元**，同比下降21.7%。主要由于签约项目减少，公司主动收缩低毛利的硬件集成业务。
*   **数据网络及其他：** 收入 **15.56亿元**，同比增长23.6%。主要得益于分销信息技术服务及机场信息技术服务的增长。

**3. 结算及清算服务 (稳健增长)**
*   **收入：** **5.55 亿元**，同比增长7.2%。
*   **规模：** 处理了约 **3.59亿张** BSP客票，代理结算客货邮运收入及费用达98亿美元。

### 基础设施与资本开支
*   **北京新运行中心：** 这是公司的重大基建项目。截至2017年底，一期工程累计支出约 **26.8亿元**（占预算的73.3%）。该中心建成后将作为公司未来的核心硬件基础。
*   **资本开支：** 2017年资本开支约为 **13.20亿元**，主要用于新一代系统建设、系统维护升级及北京新运行中心建设。预计2018年资本开支计划约为26.58亿元。

### 企业管治与风险
*   **股权结构：** 公司H股在香港联交所上市。控股股东为中国民航信息集团有限公司（持有约29.29%），13家国内航空公司持有约38.84%，H股股东持有31.87%。
*   **关联交易：** 报告详细披露了与主要股东（如南航、东航、国航集团）及其子公司的持续关联交易，主要涉及技术服务费和租赁费。公司已建立完善的内部控制机制来管理此类交易。
*   **ESG (环境、社会及管治)：**
    *   **环境：** 推行绿色办公，顺义产业园获得绿色建筑认证；温室气体排放总量约5.76万吨。
    *   **社会：** 员工总数7,862人；开展精准扶

### 企业管治与风险
*   **股权结构：** 公司H股在香港联交所上市。控股股东为中国民航信息集团有限公司（持有约29.29%），13家国内航空公司持有约38.84%，H股股东持有31.87%。
*   **关联交易：** 报告详细披露了与主要股东（如南航、东航、国航集团）及其子公司的持续关联交易，主要涉及技术服务费和租赁费。公司已建立完善的内部控制机制来管理此类交易。
*   **ESG (环境、社会及管治)：**
    *   **环境：** 推行绿色办公，顺义产业园获得绿色建筑认证；温室气体排放总量约5.76万吨。
    *   **社会：** 员工总数7,862人；开展精准扶贫工作（如神池县帮扶）；重视数据安全与隐私保护。

这份2017年报展示了中国航信在**“提质增效”**方面的决心。公司通过主动削减低毛利的系统集成业务，进一步巩固了在航空IT核心技术领域的垄断地位。同时，公司在新一代系统上的巨额投入和北京新数据中心的建设，为未来十年的数字化转型奠定了坚实的基础。
