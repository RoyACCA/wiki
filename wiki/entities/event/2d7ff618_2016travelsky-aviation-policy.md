# 2016TravelskyAviationPolicy

## Summary
这份文档是**中国民航信息网络股份有限公司（中国航信，TraveSky）**发布的**2016年年度报告**。报告详细披露了公司在2016年1月1日至12月31日期间的财务业绩、业务回顾、战略转型及重大资本运作。以下是对该年报核心内容的全面提炼：。

## Details
这份文档是**中国民航信息网络股份有限公司（中国航信，TraveSky）**发布的**2016年年度报告**。报告详细披露了公司在2016年1月1日至12月31日期间的财务业绩、业务回顾、战略转型及重大资本运作。

以下是对该年报核心内容的全面提炼：

### 核心财务业绩：利润增速显著
2016年是公司“十三五”规划的开局之年，业绩表现出**利润增速远超收入增速**的高质量增长特征。

| 核心指标     | 2016年数值 (人民币) | 同比变动 | 备注                             |
| :----------- | :------------------ | :------- | :------------------------------- |
| **营业收入** | **62.23 亿元**      | 📈 +13.7% | 达62.23亿元，较2015年增加7.5亿元 |
| **净利润**   | **24.21 亿元**      | 📈 +26.5% | 本公司权益持有人应占盈利         |
| **税前利润** | **28.70 亿元**      | 📈 +23.8% | 盈利能力持续增强                 |
| **每股收益** | **0.83 元**         | 📈 +26.9% | 基本及摊薄每股盈利               |
| **派息建议** | **0.222 元/股**     | -        | 建议派发末期股息 (含税)          |

*   **现金流：** 经营活动产生的现金流量净额为**36.45亿元**，同比增长52.8%，现金流极其充裕。
*   **资本开支：** 全年资本开支约11.6亿元，主要用于新一代航空旅客服务系统开发及北京新运行中心建设。

### 业务板块深度复盘
公司处于航空旅游分销价值链的核心环节，业务结构进一步优化，高毛利的IT服务占比提升。

**1. 航空信息技术服务 (核心支柱)**
*   **收入：** **34.96亿元**（占总收入的56.2%）。
*   **规模：** ETD系统处理订座量约**5.24亿人次**（+11.4%）；APP系统在90个机场处理出港旅客量约1430万人次。
*   **亮点：** “航旅纵横”APP用户数突破**3000万**，推出客票监控、机上选餐等功能；获得IATA新分销能力(NDC) Level 3认证；新一代民航旅客服务系统建设稳步推进。

**2. 系统集成与数据网络 (增长主力)**
*   **系统集成：** 收入9.50亿元（+47.7%），主要由于新签系统集成类项目增加。
*   **数据网络及其他：** 收入12.59亿元（+4.8%），包括分销信息技术、机场及货运物流信息服务等。

**3. 结算及清算服务 (稳健增长)**
*   **收入：** 5.18亿元（+5.1%）。
*   **规模：** 处理BSP客票约3.04亿张，代理结算收入及费用达88亿美元；IATA新一代BSP数据处理系统（IBSPs）在多国实施。

### 战略布局与重大投资
公司在2016年进行了重要的国际化布局和基础设施建设。

*   **海外收购：** 旗下新加坡公司以约**3940万美元**收购**OpenJaw Technologies Inc.** 100%股权。OpenJaw是爱尔兰公司，主要从事旅游科技及产品服务，此举旨在增强公司在旅游电商和云计算领域的技术实力。
*   **北京新运行中心：** 位于顺义的重大基建项目。截至2016年底，一期工程累计支出约22.6亿元（占预算的61.8%），预计2017年继续投入。
*   **合资合作：** 出资参与筹建**招商局仁和人寿保险**及**招商局仁和财产保险**，各出资8.75亿元，分别持有17.5%股权。

### 公司治理与股权结构
*   **股权结构：** 截至2016年底，已发行股本约29.26亿股。
    *   **内资股 (68.13%)：** 主要股东包括中国民航信息集团公司（约29.29%）及多家国有航空公司。
    *   **H股 (31.87%)：** 在香港联交所上市。
*   **董事会变动：** 2016年10月完成董事会换届，崔志雄先生连任董事长。
*   **ESG (环境、社会及管治)：**
    *   **环境：** 推行无纸化办公（电子客票、电子货单），顺义产业园获得绿色建筑认证。
    *   **社会：** 投入精准扶贫（山西神池县），开展“暖冬行动”志愿服务。

*   **税务优惠：** 公司维持“高新技术企业”资格，2016年按**15%**优惠税率缴纳企业所得税。

*   **关联交易：** 报告详细披露了与南航、东航、国航等股东及关联方（如凯亚公司）的持续关联交易，主要涉及系统服务费、租赁费等，均按公平原则或政府指导价定价。

这份年报展示了中国航信在2016年通过**“内生增长+外延并购”**双轮驱动的发展策略。公司在巩固国内民航IT垄断地位的同时，积极通过收购OpenJaw布局国际市场，并利用充裕的现金流建设基础设施，为未来的云化和数字化转型打下了坚实基础。
