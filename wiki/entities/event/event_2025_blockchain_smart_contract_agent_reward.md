# Event: 区块链智能合约+数字人民币落地代理人外航奖励

## Summary
2025年12月22日，中国航信"对账通"平台实现代理人外航奖励"区块链智能合约+数字人民币"自动结算，累计支付732笔，民航分销领域数字支付创新迈出关键一步。

## Details

### 基本信息
- **时间**：2025年12月22日
- **平台**：对账通（航旅链产品族群）
- **参与部门**：资本运营与创新业务部（牵头）、全球分销事业部
- **来源**：资本运营与创新业务部（原文）/ 智能安全业务部（现归口）

### 技术方案
- **技术**：区块链智能合约 + 数字人民币
- **场景**：代理人外航奖励自动结算
- **效果**：即核即付、业财融合效率提升、全流程风险防控

### 里程碑
- 首次：离港费用（2024年）
- 扩展：代理人外航奖励（2025年12月，732笔）
