# Event: 千穰大模型通过中央网信办生成式AI服务备案

## Summary

2024年7月12日，移动科技（中航信移动科技有限公司）自主研发的"千穰大模型"通过中央网信办生成式人工智能服务备案，备案号ZhongYangQiYe-QianRang-202406200001，序号168，属地国资委。系第4个取得网信办认证的中央企业大模型，也是民航首个垂直领域大模型。

## Details

- **备案时间**：2024年7月12日
- **公告时间**：2024年8月（网信办2024年8月批次公告）
- **备案号**：ZhongYangQiYe-QianRang-202406200001
- **备案序号**：168
- **属地**：国资委
- **研发单位**：中航信移动科技有限公司（移动科技）
- **技术架构**：融合视觉大模型、语言大模型、多模态大模型、计算大模型

> **部门归属**：千穰由**中航信移动科技有限公司**研发，不属于航信股份公司内部部门。据2026年组织调整，航信总部的AI相关工作归口**智能安全业务部**。
