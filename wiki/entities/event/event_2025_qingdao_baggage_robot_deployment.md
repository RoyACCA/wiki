# Event: 机场行李全向叉取智能机器人系统在青岛胶东国际机场部署

## Summary

2025年8月8日，青岛胶东国际机场转场4周年媒体开放日上，中国航信资本运营与创新业务部展示其自主研发的全球首个民航行李转运场景全向叉取智能机器人，已在青岛胶东国际机场W13转盘部署完成，转运效率达180件/小时以上。

## Details

- **展示日期**：2025年8月8日
- **展示平台**：青岛胶东国际机场转场4周年媒体开放日
- **展示单位**：资本运营与创新业务部
- **产品状态**：已在W13转盘部署完成
- **来源**：《机场行李全向叉取智能机器人亮相青岛胶东国际机场转场4周年媒体开放日》（作者：康茂琪，浏览量：201）

> **部门归属**：资本运营与创新业务部。据2026年组织调整，相关工作已并入**机场数智业务部**。
